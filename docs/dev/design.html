Образец элементов интерфейса

Страница собрана из настоящих стилей приложения. Это диагностика, а не витрина утверждённой системы: специализированные элементы (игровые, тренажёрные) оставлены намеренно, чтобы сравнивать их с обычными. Описание — в design.md, цифры — в design-audit.md.

Как смотреть: отличие элемента от соседа само по себе не ошибка. Спросите, оправдано ли оно ролью или состоянием. Подпись у каждого примера: роль · класс. Тёмная тема — кнопка ниже или адрес с ?theme=dark.

Пары для сравнения

  • Кнопки действий: button, .btn-primary, .bad, .calza, .quiz-secondary
  • Вкладки: .drill-tab и .stats-tab

  • Поля: input и .drill-input
  • Раскрывающиеся блоки: подсказка, раздел, тихий
  • Поверхности: .card, .result-card, .key-moment
