# Адаптивная вёрстка

Часть [CONTRIBUTING.md](../../CONTRIBUTING.md): правила вёрстки, которые проверяют тесты.

- Брейкпоинты: **≤ 719px** (телефон), **≤ 1100px** (шторка вместо правой колонки), **низкий ландшафт** (`max-height: 500px`).
- На телефоне панель действий прижата к низу экрана (зона большого пальца), все цели нажатия не меньше 44px.
- Положения мест за столом задаются в процентах (`--x/--y` для широкого стола и `--mx/--my` для телефона) и зажимаются через `clamp()`, чтобы место никогда не выходило за сцену.
- Калькулятор, Тренажёр, Упражнения, Дуэль и Симуляция собраны по той же схеме, что и Партия: основная область и **панель действий** (`.action-dock`). На телефоне панель прижата к низу экрана, на экранах от 720px и в низком ландшафте это правая колонка. Общие стили учебных вкладок лежат в `src/css/learn.css`. Все цвета интерфейса заданы переменными в `src/css/themes.css` (прописывать цвета в других CSS-файлах и в inline-стилях нельзя, это проверяет `tests/css.test.js`); так подключаются темы оформления. «Статистика» — страница без панели: кнопки сверху, таблицы помещаются в карточку.
- Шапка разделов на телефоне во всех разделах схлопывается в кнопку ☰ с заголовком раздела (атрибут `body[data-compact-nav]`); лента разделов остаётся в шапке на экранах от 720 px.
- Поля ввода не меньше 44px по высоте, шрифт 16px (iOS не увеличивает страницу при фокусе). Проверяет `tests/test_learning_layout.py`.
- Тест `tests/css.test.js` следит, чтобы в CSS не оставалось неиспользуемых классов, а в `index.html` не появились встроенные `<style>`.
