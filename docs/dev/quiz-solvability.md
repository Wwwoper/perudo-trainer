# Решаемость вопросов «Читай стол»

Вопрос викторины полезен, только если его можно решить чтением ставок. Проверка: «читающий»
(`src/quiz_reader.js`) видит то же, что игрок (свои кубики, число кубиков у каждого, ставки), отвечает
по простым правилам и сравнивается с лучшей постоянной догадкой. Замер: `node tools/quiz_skill.mjs`;
тест `tests/quiz_reader.test.js` требует запас не меньше 8 п. п. по каждому виду.

Замер на 4000 учебных раундов (доля возможных баллов):

| Вид вопроса | Лучшая догадка | Читающий | Запас |
|---|---|---|---|
| Верность последней ставки | 54,9 % | 67,9 % | 13,0 п. п. |
| Самая слабая ставка | 39,4 % | 56,1 % | 16,7 п. п. |
| Кто держит больше | 50,3 % | 63,6 % | 13,4 п. п. |
| Сколько на столе | 37,8 % | 52,6 % | 14,9 п. п. |

Правила читающего: шанс ставки по биномиальному распределению (у автора цифра вероятнее); слабая ставка —
на цифру, которую автор называл реже всего; у кого больше — у кого крупнее последняя ставка; число — свои
кубики плюс ожидание у остальных плюс 0,25 за каждого назвавшего цифру. Параметры подобраны по тем же
учебным раундам, поэтому запас слегка завышен, а запас в 8 п. п. в тесте оставлен с буфером.

## Выводы

- Ни один вид вопросов не «невозможен»: чтение ставок даёт заметный запас над догадкой. Вопрос про число
  самый шумный по баллам (даже читающий берёт чуть больше половины), но запас у него не меньше, чем у других.
- Запас небольшой, около 13–17 п. п. На серии из 20 вопросов это 2–3 вопроса при случайном разбросе
  порядка 2 вопросов. Поэтому одна серия не отделяет навык от везения: честнее смотреть на накопленную
  статистику по видам, а в итоге одной серии не делать выводов вроде «вы лучше догадки» без оговорки.
- Сигналы в учебных раундах (повторы цифры, размер ставки) идут от ботов программы. У людей они могут
  отличаться, поэтому запас стоит перепроверять на сохранённых партиях, когда их накопится достаточно.
