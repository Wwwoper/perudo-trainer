# Руководство для новичков

Страницы руководства лежат в `docs/guide/` и публикуются на GitHub Pages вместе с приложением: `https://wwwoper.github.io/perudo-trainer/docs/guide/`. Это обычный HTML без сборки.

## Как устроены страницы

- `index.html` — оглавление, список `<ol class="toc">` со всеми страницами.
- `guide.css` — общий стиль. Цвета только из переменных `src/css/themes.css`, поэтому тема страницы совпадает с темой приложения (оба живут на одном адресе и читают один и тот же `perudo.settings`; светлая тема по умолчанию).
- В `<head>` каждой страницы порядок такой: `src/theme_boot.js`, `src/css/themes.css`, `guide.css`.
- Внизу страницы блок `<nav class="pager">` со ссылками «назад» (`rel="prev"`) и «далее» (`rel="next"`): страницы идут цепочкой от оглавления.
- Картинки берутся из `docs/img` (их делает `tools/screenshots.py`); у каждой есть осмысленный `alt`. Два телефонных снимка кладутся рядом в `<div class="shots">`.

## Как добавить страницу

1. Скопируйте похожую страницу, поменяйте `title`, `description`, заголовок и текст.
2. Добавьте её в оглавление `index.html` и встройте в цепочку «назад / далее» (поправьте соседние страницы).
3. Запустите `npm test` (структура, ссылки, якоря, цвета, навигация: `tests/guide.test.js`) и `python3 -m unittest tests.test_guide_layout` (вёрстка на трёх размерах экрана и контраст в обеих темах).

Подписи кнопок в тексте должны совпадать с подписями в приложении: часть таких подписей проверяет тест.
