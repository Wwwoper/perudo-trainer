Руководство по Перудо

Короткие страницы для тех, кто открыл приложение впервые: как начать, как устроена игра и что делает каждый раздел.

  1. Быстрый стартПервая партия за минуту
  2. Правила игрыСтавки, «Не верю!», единицы-джокеры, Calza и Палифико
  3. КалькуляторВерить ставке соперника или нет
  4. ТренажёрУчебные ситуации, режимы, порог шанса, повтор ошибок
  5. УпражненияСчёт в уме: «Оценка в уме» и «Правило единиц»

Приложение работает прямо в браузере, без регистрации. Откройте его в соседней вкладке и читайте руководство рядом: так проще пробовать на ходу.

Нашли ошибку или не поняли объяснение? Напишите на странице проекта на GitHub в разделе Issues.

Цвета страницы следуют теме приложения: её можно сменить на вкладке «Статистика».
