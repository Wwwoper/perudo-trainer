## 3. Что НЕ меняем и почему

- **Логику игры** (правила ставок, Палифико, Calza, порядок хода). По ТЗ менять её без явного согласования нельзя. Расхождения README и кода предлагается устранять **правкой README**, а не кода.
- **Стили ботов** (`i % 3`). Повтор при 4–5 ботах — осознанный компромисс, пока стилей три. Меняем текст README; новых стилей не добавляем.
- **Расположение README** (`.github/`). GitHub его подхватывает, перенос не обязателен. Меняем только если владелец захочет.
- **Деплой на GitHub Pages и `index.html`.** Работают как есть, workflow не нужен.
- **Версию `2.0.0`.** Не меняем.
- **Тесты вёрстки на Python и e2e на JS.** Не объединяем: они проверяют разное. Только описываем в README.
- **Файлы без согласования не удаляем** (`build.py`, `src/app.js`, картинку): сначала решение владельца.

## 4. Риски

- **Удаление `build.py`**: если кто-то пользуется `perudo-standalone.html` как одним файлом для раздачи вне GitHub, он потеряет эту возможность. В репозитории нет workflow и релизов, которые его бы публиковали, так что вероятность низкая.
- **Удаление `src/app.js`**: ссылок на него в репозитории нет (проверено поиском), риск минимальный. Остаётся в истории git.
- **Загрузка `core.js` через `node:vm` в тесте**: тест перестаёт зависеть от того, как Node трактует расширение и `"type": "module"`, но становится чуть менее «каноничным». Альтернатива — перевести `core.js` на ES-модуль, что затронет подключение в `index.html` (`<script src>` придётся менять на модуль) и не рекомендуется.
- **`canCalza` и `app_v2.js`**: мелкая правка логики. Риск: изменить поведение для нестандартного `playerId`. Для `'human'` поведение идентично. Покрывается тестом движка.
- **Валидация в `createGame`**: если где-то в коде (или в сохранённых настройках пользователя в `localStorage`) значения выходят за 1–10 / 1–5, партия перестанет создаваться вместо тихой работы. Нужно проверить `storage.js` и обработчик кнопки «Новая партия» (ловить ошибку и показывать сообщение).
- **Перенос `LICENSE`**: ссылки на него в README придётся обновить, иначе ссылка сломается.
